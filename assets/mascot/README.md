# Big Brain Ape mascot kit

Official artwork for **Big Brain Ape The MemeCoin Sniper**.

## Usage (do not break)

| File | Use | Never |
| --- | --- | --- |
| `mascot-hero-full.jpeg` (`mascot-01`) | Homepage hero only. Full ape **plus** the candlestick chart background. | Crop, `object-fit: cover`, fixed portrait box, or edit. Show with `object-fit: contain` or `width: 100%; height: auto`. |
| `mascot-cutout.jpg` (`mascot-02`) | Small UI only: header mark, favicon, docs avatar. | Use as the homepage hero. |
| `mascot-04.jpeg` / `mascot-boss.jpg` | Head-ape / boss card accents. | Replace the uncropped hero. |
| `mascot-anim.gif` | Motion accent only. | Crop the hero from frames. |

`apps/web/public/mascot.jpg` is retired. Do not add it back.

## Troop

One Telegram bot. Head ape plus five specialists: **Scout**, **Sniper**, **Pulse**, **Ledger**, **Shield**.
