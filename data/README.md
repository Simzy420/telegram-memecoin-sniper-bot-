# Data directory

`trade-archives/` is the live UTC day-folder root (`YYYY-MM-DD`). It is **gitignored** so fills never land in git.

See [`docs/TRADE_ARCHIVES.md`](../docs/TRADE_ARCHIVES.md) for the schema. A committed EXAMPLE empty day lives at [`docs/examples/trade-archives/EXAMPLE-1970-01-01/`](../docs/examples/trade-archives/EXAMPLE-1970-01-01/).
